# File type icons

TyPad bundles unmodified Latte (light) and Mocha (dark) SVGs from [Catppuccin Icons](https://github.com/catppuccin/vscode-icons), revision `b6915da9f6889b683a110aa747de96c2820a537d`.

The bundled [MIT license](../macos/TyPad/Resources/Catppuccin-Icons-LICENSE.txt) is copied into the macOS application. No extension or network request is needed at runtime.

File tree, project tabs, and source title use the same 16-point original-color asset. Main-document and unsaved indicators remain separate. Unknown extensions use `_file`; directories match upstream names for assets, images, fonts, docs, templates, src, config and lib, with closed/open variants; unrecognized names use `_folder` / `_folder_open`; project roots use `_root` / `_root_open`.

Writing overrides: `.cls` → `latex`, `.bst` → `lib`, `.csl` → `xml`. `typst.toml` uses `typst`. Names/extensions are case-insensitive; Hayagriva YAML retains the YAML icon.

Run `bash ci/check-project.sh` for mapping, fallback, and paired appearance-resource checks. The arm64 Xcode build validates asset compilation; actual UI appearance is a separate acceptance check.
