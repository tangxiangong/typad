# iPad Chinese fallback fonts

Noto Sans SC Regular and Bold, unchanged upstream region-specific OTFs.
Source: https://github.com/notofonts/noto-cjk/tree/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/SubsetOTF/SC
Revision: `f8d157532fbfaeda587e826d4cd5b21a49186f7c`.
License: SIL Open Font License 1.1; see `OFL.txt` (upstream `Sans/LICENSE`).

These fonts provide standard CFF outlines for offline Chinese PDF rendering on iPad,
including when system fonts expose only proprietary outlines. The two fonts add approximately 16 MiB.
